El comando git branch permite crear, hacer un registro y administrar ramas dentro de un repositorio Git.
 Las ramas permiten trabajar en cambios de manera independiente sin modificar directamente la rama principal del proyecto(lo que sería una mala práctica porque en proyectos grandes, puede generar conflictos). 

 Ejemplo: git branch login.
  Este comando crea una nueva rama llamada login. 
  
   El siguiente comando, mostrará las ramas existentes y  marca con un asterisco  la rama actual:
             
                git branch
