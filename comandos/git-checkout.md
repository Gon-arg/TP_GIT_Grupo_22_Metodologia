El comando git checkout tiene dos usos principales:

1- Para cambiarte de rama, entrar y poder trabajar ahi. Ej: git checkout login
2- Crear una rama y moverte a ella al mismo tiempo. Ej: git checkout -b nueva-rama
"-b" combina git branch y git checkout en un solo comando: crea la rama y te mueve a ella directamente.
